# Моделирование игры в большой теннис

Написал проект по моделированию теннисных матчей. Проект включает сбор списка предстоящих игр, анализ статистических данных игроков и, собственно, моделирование матчей. Программа рассчитывает вероятности выигрыша игроков, по ним определяет наиболее вероятного победителя. 

На этом сайте публикуются результаты проверки разработанной математической модели на играх ATP и WTA в одиночном разряде. Сайт включает следующие разделы: 
- статистические показатели результативности прогнозов (предсказаний модели)
- прогнозы на предстоящие игры 
- история сделанных прогнозов 

> [!WARNING]
> Вся публикуемая информация носит исключительно информативный характер.
> Сайт предназначен для демонстрации работы проекта.
