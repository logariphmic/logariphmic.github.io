# Моделирование игры в большой теннис

Этот сайт посвящен проекту по моделированию теннисных матчей. Проект включает сбор списка предстоящих игр, анализ статистических данных игроков и, собственно, моделирование матчей. Модель опирается на текущую форму и стабильность игроков, которые определяются по статистическим показателям за последние игры. Программа рассчитывает методом Монте-Карло вероятности выигрыша соперников, по ним определяет наиболее вероятного победителя. 

На этом сайте публикуются результаты проверки разработанной математической модели на играх ATP и WTA в одиночном разряде. Сайт включает следующие разделы: 
- статистические показатели результативности прогнозов (предсказаний модели)
- прогнозы на предстоящие игры 
- история сделанных прогнозов
